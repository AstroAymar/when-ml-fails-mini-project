# When Machine Learning Fails

Mini-project for the course Introduction to AI & Machine Learning  
École Centrale Casablanca — Spring 2026

Authors: Yassir BAHADI and Aymar SUERY

## Project topic

This project studies failure modes of a non-linear machine learning model on the Online Shoppers dataset.

The main research question is whether a Random Forest model uses the `Month` variable as a shortcut, leading to degraded performance under temporal out-of-distribution conditions.
